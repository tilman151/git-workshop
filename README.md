# Git Like a Pro

This repository is the companion to the "Git Like a Pro" workshop.
It contains a tutorial Python project to practice intermediate and advanced git concepts on.
This includes:

- crafting readable commit histories
- solving merge conflicts
- fixing or recovering commits
- (interactive) rebasing

## Installation

The project itself uses no external dependencies, so a working Python installation is sufficient.
The workshop is intended to showcase working with git in VS Code.
In addition, the GitLense plugin for VS Code is recommended.
